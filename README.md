# NanoChat

A private, on-device AI chat app — like a nano version of ChatGPT — built on Chrome's [built-in Gemini Nano model](https://developer.chrome.com/docs/ai/built-in) (the [Prompt API](https://developer.chrome.com/docs/ai/prompt-api)). Also includes [Summarizer](https://developer.chrome.com/docs/ai/summarizer-api), [Translator](https://developer.chrome.com/docs/ai/translator-api), [Writer](https://developer.chrome.com/docs/ai/writer-api), [Rewriter](https://developer.chrome.com/docs/ai/rewriter-api), [Proofreader](https://developer.chrome.com/docs/ai/proofreader-api), and [Language Detector](https://developer.chrome.com/docs/ai/language-detection) tools.

100% local — runs entirely on your machine. No network calls, no server, no API keys. Chat history is encrypted at rest (AES-GCM, key in IndexedDB).

## Caveats

NanoChat inherits the limits of Chrome's built-in model:

- **Quality is well below frontier models.** Gemini Nano is small and on-device — expect weaker reasoning, coding, and factual recall than GPT- or Claude-class cloud models. Best for short summaries, rewrites, translations, and quick Q&A.
- **Context window is tiny** (a few thousand tokens). Long pages get truncated, long chats drop early turns. The page-summarize actions truncate aggressively for this reason.

## Requirements

- **Chrome 138+** on desktop (Windows 10+, macOS 13+, Linux, or ChromeOS Chromebook Plus)
- ~22 GB free disk space (for the Gemini Nano model component)
- 16 GB RAM **or** a GPU with 4+ GB VRAM
- The first time you use a feature, Chrome may need to download the model component. Watch progress at `chrome://on-device-internals`.

## Install

NanoChat ships in two forms. The **extension** adds a toolbar popup and right-click menu so you can summarize or ask questions about the current page. The **single-file** form is one HTML file you double-click — no install, no permissions.

### Extension (recommended — adds page actions)

1. Clone or [download a ZIP](https://github.com/jhpacker/nanochat) of this repo and unzip it.
2. Open `chrome://extensions`, enable **Developer mode** (top right), click **Load unpacked**, and select the [`extension/`](extension/) folder.
3. Click the NanoChat toolbar icon to chat, or right-click any page (or use the toolbar popup) for the page actions described below.

### Page actions (extension only)

Right-click or the toolbar popup exposes four actions on the current tab:

- **Summarize this page** — auto-sends a 3–5 bullet summary prompt.
- **Ask about this page** — prefills the input so you can type your own question.
- Each also has a **(with images)** variant that captions up to 10 of the largest on-page images (fresh multimodal session per image, 2–4 sentences) and folds the captions into the context as text.

**Heads up: the *(with images)* variants mostly fail in the wild.** To keep the no-network promise, NanoChat reads pixels from already-painted `<img>` via `OffscreenCanvas` instead of refetching. Cross-origin images without CORS taint the canvas and are silently skipped — and most site images come from a CDN without CORS headers, so these runs often caption zero images. Works best when images are same-origin or the host sets `crossorigin` / `Access-Control-Allow-Origin` (which many sites don't).

### Single-file (no install)

Pick whichever is easiest:

- **Copy/paste:** open [`index.html` raw](https://raw.githubusercontent.com/jhpacker/nanochat/main/index.html), select all + copy, paste into a text editor, save as `nanochat.html`, double-click to open in Chrome.
- **ZIP:** [download the repo](https://github.com/jhpacker/nanochat), unzip, double-click the root `index.html`.
- **Git:** `git clone https://github.com/jhpacker/nanochat.git && open nanochat/index.html`

You'll get a `file:///…/nanochat.html` URL — no web server required. If Chrome isn't your default browser, right-click the file → **Open With → Google Chrome**.

## Development

Source of truth is [`extension/`](extension/) (Manifest V3 form). The root `index.html` is generated by `node build.js`, which inlines `extension/styles.css` and `extension/app.js` into `extension/index.html`. The extension shell (`background.js`, `popup.*`, `manifest.json`) isn't part of that build.

The root `index.html` is checked in (it powers the copy/paste and ZIP flows above). A pre-commit hook keeps it in sync — enable once per clone:

```bash
git config core.hooksPath .githooks
```

After that, committing changes to `extension/{index.html,app.js,styles.css}` reruns the build and re-stages the root `index.html`.

## Troubleshooting

- **Tabs are greyed out / struck through** → that API isn't available in your Chrome build. Some are still in origin trial (Writer, Rewriter, Proofreader) and may need flags enabled at `chrome://flags`.
- **"Model component is being downloaded"** → wait for Chrome to finish downloading Gemini Nano. Check status at `chrome://on-device-internals`.
- **Audio input fails** → audio requires a GPU. CPU-only machines can't use it.
